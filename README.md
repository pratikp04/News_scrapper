Task 3 : Web Scraper for News Headlines.
Name : Pratik Patil
Comapany : Elevate Labs



This task involves building a Python web scraper to automatically extract top news headlines from a public news website. It demonstrates the basics of HTTP requests using the requests library, HTML parsing with BeautifulSoup, and data extraction from webpage elements like <h2> and <h3> tags. The scraped headlines are saved into a text file for easy access and further use. This beginner-friendly project teaches key concepts in web scraping, HTML structure navigation, and automated data collection, making it useful for data gathering, monitoring news, or learning web automation skills.
